## 1. เป้าหมาย

ตอบข้อสงสัยของ reviewer (NCCY2026 Paper #37, Review A/B/C) เรื่อง sample-selection bias ของตัวเลข 91% ซึ่ง malicious IOC ถูกคัดจาก ThreatFox ที่ระบบใช้ให้คะแนนด้วย โดยทดสอบ Flow A บน **URL** ที่คัดและตัดสิน label จากแหล่งที่ไม่อยู่ใน 6 scoring sources (FeodoTracker, C2 Trackers, Spamhaus, Tor exit nodes, SSLBL, ThreatFox)

ขอบเขต: ชุดนี้ครอบคลุม **เฉพาะ URL** ไม่ใช่ IP, domain หรือ hash

## 5. การรายงาน

- รายงานผล overlap หลักเป็นสัดส่วน malicious URLs ที่ทราบว่าอยู่ใน C2 Trackers หรือ ThreatFox ณ pull time พร้อม Wilson 95% CI; นี่คือ coverage ของแหล่งข้อมูลที่ระบบใช้ได้กับ URL
- รายงาน recall ของ malicious URLs ทั้งชุด. Exact-URL overlap ที่สังเกตได้มี 0 แถว จึงไม่มี exact-overlap recall ให้คำนวณ; host-level overlap มี 6 แถวและรายงานผลในกลุ่มนั้นเป็น consistency check เชิงพรรณนา โดยไม่ตั้งความคาดหวังว่า exact-URL evaluation ต้องจับ host-level hit และไม่ตั้งเกณฑ์ผ่าน/ไม่ผ่าน
- รายงาน strict `non_overlap:any` ตามจำนวนที่ยืนยันได้; เมื่อ source status ไม่ครบ ให้รายงาน unknown แยกต่างหาก ไม่จัด unknown เป็น non-overlap. ในข้อมูลรอบนี้ C2 เป็น partial ทั้ง 256 แถว ทำให้ strict `non_overlap:any` มี 0 แถว; ห้ามสร้างนิยามหรือชุดย่อย non-overlap ใหม่เพื่อให้มีตัวเลข
